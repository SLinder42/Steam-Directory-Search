# Steam Directory Search
Providing information on Steam games via API search

Searching for games on Steam is a bit cumbersome on the web and in the application because of how lists are loaded. Steam does have a way of searching the games via publicly available API, so this project seeks to save a list of games from the search to a local file, preferably a csv file. Then with a Python script a user can search for information on games.
Game information includes the name of the game, the release date, the price of the game, and the minimum amount of the game price when discounted. Further implementation would allow searching for a list of free to play games, the list of early access games, and the list of games removed from Steam whether by search, purchase, or database entry.
